# Signed contributor agreements

One file per contributor, named `<github-username>.md`, holding a filled-in
copy of the signing block from
[CONTRIBUTOR-LICENSE-AGREEMENT.md](../CONTRIBUTOR-LICENSE-AGREEMENT.md).

You add yours in your first pull request. One signature covers everything you
contribute afterwards, so this happens once and then never again.

The file has to be added by a commit authored by you. That is what makes it a
signature rather than a line of text somebody else could have typed.
