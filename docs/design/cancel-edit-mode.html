Cancel and exit edit mode

The backup set detail page at /sets/<source>/<set>. Edit is a mode, each box saves itself, and today the only way out is SAVE ALL & EXIT EDIT. This adds the other way out and is precise about what it can and cannot take back.

2 The confirmation, and the ledger that makes it honest

The dialog names every box by name and puts it on one of two sides. It never claims to undo a save, because this page has no undo: the per-box Save already wrote to config.yaml and the engine already hot-reloaded it.

Cancel is not an undo. Each box saved on its own, and Host is in the configuration the engine is running right now. To put it back, edit it again.

3 Cancelling out from under a pending refusal

A save that alters what host keys this set trusts comes back refused, with both fingerprints to compare. Cancel while that banner is up drops the acknowledgement along with the draft, and says so, because a dialog that only counted boxes would be silent about the one thing an operator was part-way through deciding.

What CANCEL does from here The refused body is dropped with the draft. No acknowledgement is sent, nothing is written to this set's known_hosts, and the key on record stays the one on record. The set is not halted by cancelling and the edit hold is released, so the schedule resumes.
4 What reaches the terminal

Leaving edit mode is an event, and a discarded draft is exactly the kind of thing an operator later swears they saved. Both exits report into the global terminal (G1.2).
