skipped is a first-class outcome, not a quiet pass, exactly as mediumcheck.Skipped argues: a surface that draws an unattempted authentication as anything but "this was never tried" has told an operator their credentials are fine on the strength of a step that never ran.
Every press names the command that does the same thing. The $ line above each test is the epic's standing rule: copy-pasteable as shown, naming the set by the full source/backup-set id every surface prints, carrying --config when the deployment is not on the packaged default, and never carrying a credential (the connection details come from the configuration, which is why the route takes a set id and not a candidate).

The global terminal is the same lines, unfiltered. This one is ?backup_set=api-server/var-backups; the docked one (G1.2) is the whole feed with a set column, and both read one buffer in one process, so a line cannot appear in one and not the other. What belongs on which was G1.5 (#593)'s call and it went strict: a set's feed is that set's own ring and nothing else, with no allowlist of deployment events that "still belong", because the permissive version is exactly what made every strip on the dashboard read the same. So the cycle-start line this mockup used to draw here is in the global terminal now, and this page inherits that decision rather than making a second one.
